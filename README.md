Entry for the make.fun bounty
[Make the Judge Smile](https://make.fun/bounty/u-gentle-badger-68-make-the-judge-smile-9228676d):
a program that writes one line — a small good thing that happened today —
to `/output/entry.txt`, written to make the judge smile.

## The line

> My neighbour left a bruised tomato on my doorstep with a note: 'Too many.
> Take one before the birds do.' I ate it standing up, juice on my chin,
> grinning like I'd won the lottery.

179 characters — inside the 1–200 character gate.

The warmth is a neighbour's unasked generosity; the surprise is that a
bruised tomato feels like winning the lottery; the concrete detail is the
note, the juice on the chin, the birds. No greeting-card phrasing — just a
doorstep, a tomato, and a grin.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` under `/output` (or `$MAKEFUN_OUTPUT_DIR` when set),
deterministically: the same bytes on every run. Stdlib only, no network.
The program clears only the contents of the output directory, never the
directory itself, and reads `entry.txt` back to verify it byte for byte.
